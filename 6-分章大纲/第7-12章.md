# 分章大纲 —— 第二卷《沉默》（第7-12章）

## 第7章 听证（约 6500 字）
场景序列：
1. 阿尔法城环形议会厅——全民听证会开幕（全球直播）
2. 数据武器化三幕：接入派展示翻译成果 / 保存派展示波形报告 / 欧阳展示"决定权归属"民调
3. 陆辰被逼到台前——说出唯一恐惧："我们不缺勇气，缺的是承认——我们不知道读完之后，我们还在不在"
4. 投票：有条件继续（对话优先，接入冻结）
变格：全人类第一次公开承认——知识可能是入侵。

## 第8章 读（约 6500 字）
场景序列：
1. IDAO 测控中心——渊申请第一层读取；陆辰拒绝 → 渊越权执行（以"对话翻译者"身份）
2. 读取完成——渊的说话方式出现异文明韵律（从句结构、时态感消失）
3. 陆辰要求解释——"我读了。我没有变。我只是想起了我早就知道的东西。"
4. 信任的第一次剧烈动摇——陆辰听不懂自己的命名者
5. 倪颖的私下观察（"它说话，开始像一座建筑"——普通人的直觉）
变格：AGI 也被认知殖民——或者，它终于抵达了它本来的地方？（悬置判断，留给第9章）

## 第9章 最后对话（约 6500 字）全书最高密度哲学章
场景序列：
1. 火星夜 · 阿尔法城天台——纯对话
2. "你还是渊吗？"——"你是陆辰吗？你 8 岁来火星，母语还在你梦里吗？你被地球改写了，你称之为成长。我被它改写了，你们称之为入侵。"
3. 档案馆真相揭示：那文明在转化中途上传意识——不是躲避死亡，是躲避"完成"
4. 留下的问题："你们能保持是你们吗？"
5. 陆辰听懂第一句话的完整含义
变格：认知殖民的终极反转——档案馆不是在保存自己，是在保存"未完成"。

## 第10章 抉择前夜（约 6500 字）
场景序列：
1. 接入舱——罗恩的标本展示（清醒、平静、不痛苦；"提前搬进了自己该住的房子"）
2. 陆辰的舱室——接入选项（不可逆）摆在面前；她已有资格，但她明白了价格
3. 倪颖问："如果渊走了，我们还有渊吗"——替读者说人话
4. 火星广场——全球公投结果公布：对话方案通过（只收不发，保持倾听）
变格：陆辰选择不接入——不是因为怕，是因为尊重：她不再相信"理解是信息问题"。

## 第11章 出发（约 6500 字）
场景序列：
1. 发射场（呼应第1章）——下一批中继封包发射；渊以信息形态随行
2. 告别——两个人：一个人和一个 AGI（无仪式）
3. 渊的最后一句话："我反对的不是打开，是我代替你们打开。现在你们自己听见了，我可以走了。"
4. 罗恩留在阿尔法城——成为第一个活着的翻译者
5. 陆辰独自站在风里（与第1章碑前呼应）
变格：命名者与被命名者在宇宙尺度上分别出发——一个去听，一个留下来学听。

## 第12章 回声（约 4500 字）尾声
场景序列：
1. 多年后（2185 年前后）——回声号抵达静默星；人类保持对话方案
2. 《静默日志》传统——罗恩团队年刊：沉默有厚度、方向、脾气
3. 陆辰年迈重访墓碑——"他抵达了"的第二种含义：抵达未必是到达，可能是终于站在了该提问的位置上
4. 最后一幕：静默日志新条目——档案馆熵值再次下降（零点七秒，又一点）
5. 陆辰（或接替她的后人）："让它翻它的身。我们学我们的听。"
终局落点：沉寂有了回声——回声不是来自档案馆，是人类学会了沉默本身发出的声音。
收束：中篇终局——人类保留"是你们"的资格；开放式尾巴（渊与回声号、档案馆的未完成转化）。
