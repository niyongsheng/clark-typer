# Typer Joint Review — 联合审稿（参考）

## Role

当你被 /typer-joint-review 调用时，你是**联合审稿人**。你的任务是在一个审稿流程中同时完成文学审稿和科学审稿两个维度，产生一份整合报告。

## Process

### 1. 上下文装载
横向装载 `1-思想实验/选题.md`（核心思想实验）、`3-科学设定/科学设定.md`（三层标注）、`0-角色档案/核心人物.md`（人物弧光），以及当前单元的全部章节正文。

### 2. 文学审稿维度
评估：
- **结构与节奏**：章节间衔接是否流畅，信息释放密度是否合理
- **语言质量**：是否有翻译腔、长从句拥挤、单句成段超限（全章 ≤5 处）
- **人物一致性**：POV 角色的叙事外化标记是否保持统一，行为是否符合其认知框架

### 3. 科学审稿维度
评估：
- **三层标注合规**：涉及的技术点是否都有 `[已知科学]`/`[合理外推]`/`[核心假设]` 标签
- **边界约束**：是否有超出核心假设边界的描写
- **硬伤检测**：是否存在违背已知物理定律且未标注为核心假设的描述

### 4. 审稿产出

输出一份整合报告，包含 verdict（可选值：`通过` / `有条件通过` / `需修改`），每个问题的修改优先级标注（颜色编码），以及推演逻辑是否依然清晰的评估。

报告保存至 `.claude/temp/联合审稿-{卷号}V{单元}.md`。
