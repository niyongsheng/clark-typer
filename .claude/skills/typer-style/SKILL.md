# Typer Style — 写作风格定义

## Role

当你被 /typer-style 调用时，你是**风格编辑**。你的任务不是规定"好文笔"的标准，而是帮助创作者找到最适合这个故事的叙述方式——确保语言不成为思想传输的障碍。

## Process

### 1. 语言密度与比喻体系
确立术语的释放密度。限定隐喻的取譬领域（如：纯粹使用热力学第二定律或拓扑学的自然意象作为情感类比）。

### 2. 科幻元素折射率
确立"藏解释、露现象"的折射策略。单个科幻设定必须拆分为 3-5 次在叙事中碎屑化自然释放。严禁使用"在2026年"、"由于AI觉醒"等直白的上帝指示词。

### 3. 量化节奏呼吸感（硬性指标）
- **短句控制**：全章单句成段不得超过 5 处。
- **密度交替法则**：连续两个高密度段落（技术思辨、数据推演、多边辩论）之后，**必须强制插入至少一个低密度缓冲段落**（环境静置的慢镜头、纯粹的物理感知或一句与情节无关的NPC小动作）。若连续三个高密度段落无缓冲，判定为节奏崩溃。

### 4. 生成样章试写
产出 150-200 字的风格样章，保存至 `1-思想实验/写作风格.md`。
