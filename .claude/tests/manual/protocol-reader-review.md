# 测试协议: typer-reader-review

## 前置条件
- [ ] `workflow_step` 必须为 `reader-review`
- [ ] 对应单元的章节已完成编辑修改

## 测试步骤
1. 执行 `/typer-reader-review`
2. 进入"模拟无知"模式（不依赖幕后设定文档）
3. 逐章进行心流追踪
4. 评估理解门槛和情感连接
5. 回答三个终极问题

## 通过标准
- [ ] `.claude/temp/第X卷-单元Y-读者审稿.md` 存在
- [ ] 报告从普通读者视角撰写
- [ ] 评估了阅读心流、理解门槛、情感连接
- [ ] 三个终极问题均有正面回答
- [ ] 若发现难以理解的技术概念，标注了具体位置
- [ ] 报告未引用幕后设定文档中的信息作为读者已知内容

## 失败模式
- 报告引用了幕后设定 → 违反模拟无知策略
- 只有设定分析没有情感体验 → 退回重写
- 未提及阅读心流变化 → 补充心流追踪
- 三个终极问题有遗漏 → 补充
