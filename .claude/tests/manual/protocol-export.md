# 测试协议: typer-export

## 前置条件
- [ ] `workflow_step` 必须为 `export`
- [ ] `7-正文/` 下所有章节已完成

## 测试步骤
1. 执行 `/typer-export`
2. 检查工具链可用性（pandoc、python 库等）
3. 加载所有章节文件和元数据
4. 生成 TXT 纯文本
5. 生成 EPUB 电子书
6. 生成 PDF 排版

## 通过标准
- [ ] `打包发布/` 目录非空
- [ ] TXT 文件：UTF-8 编码，章间空双行，以"第X章：[标题]"分隔
- [ ] EPUB 文件：标准格式，NCX 目录索引，元数据完整
- [ ] PDF 文件：出版级排版，对称页边距，页码页眉
- [ ] 元数据（书名、作者名）正确取自 `选题.md`

## 失败模式
- 工具链缺失导致某格式失败 → 提示安装依赖
- TXT 编码非 UTF-8 → 重新编码
- EPUB 缺少目录或元数据 → 补充
- 章节标题格式不统一 → 标准化标题格式
- workflow_step 未推进到 `wrap` → 手动检查
