# 测试协议: typer-writer

## 前置条件
- [ ] `workflow_step` 必须为 `write`，且对应章节状态为 `pending`
- [ ] `6-分章大纲/` 对应章节的大纲已存在

## 测试步骤
1. 执行 `/typer-writer`
2. 验证状态读取正确、上下文装载完整
3. 输出 `.txt` 格式正文
4. 出声读一遍验证流畅度
5. 自检单句成段数量 ≤5
6. 更新 `current-state.md` 和 `chapter-snapshot.md`
7. 触发 `typer-index` 索引

## 通过标准
- [ ] `7-正文/第X章.txt` 文件创建
- [ ] 文件是 `.txt` 格式，不是 `.md`
- [ ] 内容没有审稿标注、内心独白或确认客套话
- [ ] 单句成段 ≤5 处
- [ ] 无翻译腔、无冗长从句
- [ ] 科技现象通过人物感知呈现（藏解释、露现象）
- [ ] `chapter-snapshot.md` 追加了新条目
- [ ] `current-state.md` 对应章节状态已更新
- [ ] `typer-index` 调用成功（或失败日志已记录）

## 失败模式
- 输出了 `.md` 而非 `.txt` → 格式违规，必须重写
- 含审稿标注或确认套话 → 删除非正文内容
- 单句成段 > 5 → 合并相邻段落
- 密集技术段落无低密度缓冲 → 插入环境描写或物理感知
- 索引调用失败但无错误日志 → 补充日志记录
- workflow_step 推进异常 → 手动修正
