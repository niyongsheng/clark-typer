# 测试协议: typer-science-review

## 前置条件
- [ ] `workflow_step` 必须为 `science-review`
- [ ] `typer-review` 已通过（flow-through 模式）
- [ ] 单元 ≥4 章

## 测试步骤
1. 执行 `/typer-science-review`
2. 逐条抽取物理/数学断言，形成判定矩阵
3. 进行原创性极限压力测试
4. 检查 POV 视镜绑定
5. 若有严重违反物理规律且超出核心假设边界，触发熔断

## 通过标准
- [ ] 报告保存至 `.claude/temp/`
- [ ] 物理断言矩阵以表格形式呈现
- [ ] 每个断言有合规判定（✅正确/⚠️有误/❓不确定/💡标注缺失）
- [ ] 异常信号特征与经典科幻作品比对（素数序列等被标记 ⚠️）
- [ ] POV 视镜绑定测试通过
- [ ] 严重硬伤时工作流已被拦截（熔断）

## 失败模式
- 物理断言矩阵缺失 → 退回补充
- 使用了素数序列/黄金比例等经典套路未标记 → 标记 ⚠️ 并退回
- 科学异象任何 STEM 毕业生都能识别 → POV 绑定不足
- 熔断后未暂停流程 → 违反安全规定
