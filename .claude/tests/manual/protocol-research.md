# 测试协议: typer-research

## 前置条件
- [ ] `workflow_step` 必须为 `research`
- [ ] `3-科学设定/科学设定.md` 存在

## 测试步骤
1. 执行 `/typer-research`
2. 明确研究目标类型（已知科学确认 / 外推工程链 / 硬伤冲突）
3. 对不确定的近期细节使用 WebSearch
4. 研究成果沉淀至 `8-参考资料/`
5. 核心发现追加到 `科学设定.md` 参考资料字段
6. 若发现严重违反物理定律，触发熔断

## 通过标准
- [ ] `8-参考资料/` 非空
- [ ] `3-科学设定/科学设定.md` 的参考资料字段已更新
- [ ] 研究目标明确分类（已知/外推/假设）
- [ ] 若触发熔断，流程已暂停且用户已被告知
- [ ] 没有将核心假设伪装成已知科学

## 失败模式
- 研究内容与写作需求不符 → 重新定义研究目标
- 熔断触发后流程继续推进 → 违反安全规则，必须回退
- 未使用 WebSearch 查证近期不确定数据 → 建议补充搜索
- workflow_step 未推进到 `outline` → 手动检查
