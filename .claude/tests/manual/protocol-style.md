# 测试协议: typer-style

## 前置条件
- [ ] `workflow_step` 必须为 `character`
- [ ] `0-角色档案/核心人物.md` 存在

## 测试步骤
1. 执行 `/typer-style`
2. 确立语言密度和比喻体系
3. 确定科幻元素的折射率策略
4. 设定量化节奏指标（短句控制、密度交替）
5. 产生 300-500 字风格样章

## 通过标准
- [ ] `1-思想实验/写作风格.md` 存在
- [ ] 包含术语释放密度和比喻取譬领域
- [ ] 包含折射率策略（"藏解释、露现象"）
- [ ] 节奏指标量化：单句段控制、密度交替法则
- [ ] 样章 ≥300 字且体现描述的风格特征
- [ ] 无"在2026年"、"由于AI觉醒"等直白指示词

## 失败模式
- 节奏指标未量化 → 退回定义具体数字
- 样章太短 (< 300 字) → 要求扩展
- workflow_step 未推进到 `structure` 或 `research` → 手动检查
