# 测试协议: typer-review

## 前置条件
- [ ] `workflow_step` 必须为 `review` 或 `joint-review`
- [ ] 对应单元的章节已写完
- [ ] 若为 joint-review 模式，单元 ≤3 章

## 测试步骤
1. 执行 `/typer-review`
2. 根据单元规模自动进入纯文学审稿或联合审稿模式
3. 大单元检查：密度交替、单句段间距、最危险信号
4. 小单元合并科学维度检查
5. 输出 verdict

## 通过标准
- [ ] 报告保存至 `.claude/temp/`
- [ ] verdict 为 [通过]、[有条件通过] 或 [需修改] 之一
- [ ] 密度交替检查发现了违规段落（如果有）
- [ ] 单句段间距 < 200 字被标记警告
- [ ] 若为需修改，`workflow_step` 已被修改为 `editor`
- [ ] 若为小单元联合审稿，报告同时覆盖文学和科学维度

## 失败模式
- verdict 不是三种标准值之一 → 修正
- 判定需修改但 workflow_step 未被修改为 `editor` → 手动修正
- 大单元联合审稿（应该分步）→ 模式错误，退回
- 密度交替有违规但未检出 → 补充审稿
