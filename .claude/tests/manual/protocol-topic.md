# 测试协议: typer-topic

## 前置条件
- [ ] `workflow_step` 必须为 `intent`
- [ ] `1-思想实验/创作意图.md` 已存在（来自意图对谈）

## 测试步骤
1. 执行 `/typer-topic`
2. 与创作者进行意图深度对谈，抽取 4 维度记入 `创作意图.md`
3. 生成 3 个"科学假设 + 人文追问"选题
4. 对每个选题进行原创性压力测试（比对 ≥3 部经典作品）
5. 若选题雷同，标记 `[需变奏]` 并绑定 POV 专业视镜
6. 锚定工作标题，记入 `选题.md`
7. 创作者不满意时触发退路循环（最多 3 轮）

## 通过标准
- [ ] `1-思想实验/创作意图.md` 包含核心动机、篇幅预期、感觉与氛围、创作约束
- [ ] `1-思想实验/选题.md` 存在且包含标题
- [ ] 生成了 3 个选题（至少创作者选择了 1 个或进入退路循环）
- [ ] 选题满足"一个科学假设 + 一个人文哲学追问"结构
- [ ] 退路循环最多重复 3 次

## 失败模式
- 创作者对全部 3 轮选题均不满意 → 建议暂停，重新思考方向
- 选题与已知作品高度雷同但未标记 `[需变奏]` → 退回修改
- `workflow_step` 未推进到 `settings` → 手动检查状态文件
