# 测试协议: typer-editor

## 前置条件
- [ ] `workflow_step` 必须为 `editor`
- [ ] 审稿报告（文学/科学 或 联合）已存在

## 测试步骤
1. 执行 `/typer-editor`
2. 装载审稿报告，确立修改清单
3. 按优先级修复：科学硬伤 > 一致性矛盾 > 文学润色
4. 最小动刀原则，不重写可接受段落
5. 同步更新元数据

## 通过标准
- [ ] 修改按优先级执行
- [ ] 可接受的段落没有被推翻重写
- [ ] 未引入未经测试的全新设定
- [ ] `chapter-snapshot.md` 受影响行有 `(编辑修改)` 标记
- [ ] 若删除了有价值文字片段，已沉淀至 `9-素材碎片/`
- [ ] `0-角色档案` 中受影响角色已同步更新

## 失败模式
- 修改引入了新的不一致 → 需要补充 consistency 扫描
- 科学硬伤未优先处理 → 重新排优先级
- 推翻重写可接受段落 → 违反最小动刀原则
- 删除了有质感的文字未沉淀 → 补充至 9-素材碎片
