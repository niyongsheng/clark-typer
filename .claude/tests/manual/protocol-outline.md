# 测试协议: typer-outline

## 前置条件
- [ ] `workflow_step` 必须为 `research`
- [ ] `0-角色档案/核心人物.md`、`1-思想实验/写作风格.md`、`1-思想实验/选题.md`、`2-世界观设定/世界观.md` 存在

## 测试步骤
1. 执行 `/typer-outline`
2. 验证系统读取了角色、风格、选题、世界观文件
3. 按思想实验阶段组织分卷结构
4. 标注单元章节数量
5. 为每章生成五维死锁大纲

## 通过标准
- [ ] `4-分卷大纲/`、`5-剧情单元/`、`6-分章大纲/` 均已生成
- [ ] 分章大纲包含五个维度：[认知框架展示]、[情感锚点分布]、[世界质感锚定]、[设疑具体性]、[临场张力点]
- [ ] 剧情单元按"设定→冲突→发现→反思"闭环切分
- [ ] 单元规模已标注章节数量
- [ ] 每章调用了 `核心人物.md` 中的具体叙事外化标记
- [ ] 临场张力点不是"读信/读报告"

## 失败模式
- 五维死锁缺失任意一项 → 大纲无效，退回补充
- 为读信/读报告作为临场张力 → 必须重写为两个人同空间的交互
- 单元规模分流标注缺失 → 补充标注
- workflow_step 未推进到 `write` → 手动检查
