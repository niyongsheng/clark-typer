# 测试协议: typer-character

## 前置条件
- [ ] `workflow_step` 必须为 `settings`
- [ ] `2-世界观设定/世界观.md` 和 `3-科学设定/科学设定.md` 存在

## 测试步骤
1. 执行 `/typer-character`
2. 验证系统读取了世界观和科学设定
3. 为每个角色定制专业视镜（认知框架）
4. 配置 ≥4 个叙事外化标记（含 ≥1 个非职业维度）
5. 若涉及 AI/AGI，遵守非人智能体约束
6. 生成人物关系图谱

## 通过标准
- [ ] `0-角色档案/核心人物.md` 存在
- [ ] 每个角色的外化标记 ≥4 个
- [ ] 每个角色至少有 1 个非职业维度标记
- [ ] `0-角色档案/关系图谱.md` 存在，包含核心关系网和关系变化预设
- [ ] AI/AGI 角色没有"它觉醒了"类廉价拟人化
- [ ] 角色的专业视镜与故事思想实验匹配

## 失败模式
- 角色不足 4 个外化标记 → 退回补充
- 关系图谱缺失 → 必须补充（必填项）
- 角色职业视角与剧情需求不匹配 → 建议调整
- workflow_step 未推进到 `style` → 手动检查
