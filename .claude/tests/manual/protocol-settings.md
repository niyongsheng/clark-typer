# 测试协议: typer-settings

## 前置条件
- [ ] `workflow_step` 必须为 `topic`
- [ ] `1-思想实验/选题.md` 和 `1-思想实验/创作意图.md` 存在

## 测试步骤
1. 执行 `/typer-settings`
2. 验证系统读取了选题和创作意图
3. 推演时代定位、历史分叉点、政治经济形态、技术垄断、文化禁忌
4. 对技术栈进行三层标注（[已知科学]/[合理外推]/[核心假设]）
5. 确立"不可妥协的命题"作为哲学边界

## 通过标准
- [ ] `2-世界观设定/世界观.md` 创建且包含社会结构、技术格局
- [ ] `3-科学设定/科学设定.md` 创建且所有技术点有三层标签
- [ ] 标签使用准确：[已知科学] 标注真实理论，[核心假设] 标注虚构基石
- [ ] "不可妥协的命题"明确写在科学设定末尾
- [ ] 无模糊/未标注的技术点

## 失败模式
- 技术点未标注三层标签 → 退回
- 核心假设被包装为已知科学 → 违反科学诚实，必须修正
- workflow_step 未推进到 `character` → 手动检查
