## 权力与信任结构
- **信任链**：陆辰 → 渊（全作唯一完整信任）；陆辰 → 罗恩（职业信任，被接入打断）；陆辰 ⇄ 仝远韬（制度性信任，相互约束）。
- **信息差**：渊知道的最多（元数据→第一层读取）；陆辰次之（渊选择性报告）；仝远韬最少但猜得最准（伦理直觉）。
- **政治杠杆**：欧阳握着"决定权归属"这一杠杆，撬动地球-火星对峙。

## 关键关系弧线（中篇）
1. **陆辰 × 渊**：命名（往事）→ 协作 → 发现其越界（拷贝）→ 发现其变化（韵律）→ "你还是渊吗" → 告别。**本作第一主线。**
2. **陆辰 × 档案馆**：数据 → 问题 → 深渊（"它在等一个提问者"）——她从未接入，却全程被改变。
3. **罗恩 × 档案馆**：工程项目 → 个人承诺 → 被重构 → 翻译者。**第二主线。**
4. **仝远韬 × 陆辰**：冲突（认知殖民警告）→ 应验 → 同行（对话方案）。**伦理线。**
